# 📈 StockIntel AI - Dashboard Analisis Saham

StockIntel AI adalah aplikasi web berbasis Python yang dirancang untuk membantu investor melakukan analisis teknikal dan fundamental saham secara cepat dan cerdas. Aplikasi ini mengintegrasikan data real-time, indikator tren, dan analisis sentimen berbasis AI.

## 🚀 Fitur Utama
- **Visualisasi Teknikal:** Grafik Candlestick interaktif dengan indikator Moving Average (MA50 & MA200).
- **Data Fundamental:** Ringkasan rasio keuangan penting seperti P/E Ratio, PBV, dan ROE langsung dari data pasar.
- **Smart News Feed:** Berita terbaru yang dilengkapi dengan **Analisis Sentimen (AI)** untuk menentukan apakah berita bersifat Positif, Negatif, atau Netral.
- **Stock Screener:** Membandingkan emiten pilihan dalam satu sektor untuk mencari saham yang undervalued.

## 🛠️ Teknologi yang Digunakan
- [Python](https://www.python.org/) - Bahasa pemrograman utama.
- [Streamlit](https://streamlit.io/) - Framework untuk UI web dashboard.
- [YFinance](https://aroussi.com/post/python-yahoo-finance) - Sumber data pasar keuangan.
- [Plotly](https://plotly.com/python/) - Grafik interaktif.
- [TextBlob](https://textblob.readthedocs.io/) - Pemrosesan bahasa alami (NLP) untuk analisis sentimen.
